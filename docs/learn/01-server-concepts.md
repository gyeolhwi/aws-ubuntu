# 01 서버 개념·서버, VPS, 클라우드, IP, 포트, SSH

> 학습 시리즈: **01** → [02 Lightsail](02-lightsail-instance.md) → [03 Docker](03-docker-basics.md) → … 전체 순서는 [README](../../README.md).

이 시리즈는 서버 한 대(`aws-ubuntu-1`)에 여러 사이트를 `서비스명.hwiii.com` 형식으로 올리기까지 **실제로 한 일**을 순서대로 기록한다.
전체 비유는 이렇다: **서버 = 건물, 컨테이너 = 방, DNS = 주소 안내, 프록시 = 1층 안내 데스크.**

## 1. 서버

| 용어 | 한 줄 정의 | 비유 |
|---|---|---|
| **서버** | 요청을 받으면 응답을 돌려주는, 24시간 켜져 있는 컴퓨터 | 24시간 문 여는 건물 |
| **클라이언트** | 서버에 요청하는 쪽. 브라우저, 앱 | 방문객 |
| **호스팅** | 서버 컴퓨터를 빌려 쓰는 서비스 | 건물 임대 |
| **VPS** (Virtual Private Server) | 큰 물리 서버 하나를 나눠 만든 가상 서버. 나만 쓰는 OS와 root 권한이 있다 | 큰 빌딩의 한 층을 통째로 임대 |
| **클라우드** | AWS, GCP처럼 서버·DB·저장소를 필요할 때 빌려 쓰고 쓴 만큼 내는 방식 | 필요할 때 층을 늘렸다 줄였다 하는 빌딩 |

우리 서버는 AWS의 **Lightsail**에서 빌린 VPS다. Lightsail은 AWS 안에서 가장 단순한 고정 요금 VPS 상품이다.

## 2. IP 주소와 포트

| 용어 | 한 줄 정의 | 비유 |
|---|---|---|
| **IP 주소** | 네트워크 안의 컴퓨터 주소. 예: `203.0.113.10` | 건물 번지수 |
| **공인 IP** | 인터넷 어디서나 접근할 수 있는 주소 | 도로명 주소 |
| **사설 IP** | 내부 네트워크에서만 쓰는 주소 (`172.x`, `10.x`, `192.168.x`). 우리 서버의 호스트명 `ip-172-26-...`이 이것이다 | 건물 내부 호수 |
| **고정 IP** | 재부팅해도 바뀌지 않는 공인 IP | 영구 번지수 |
| **포트** | 한 컴퓨터 안에서 어느 프로그램에 연결할지 정하는 번호 (0~65535) | 건물 안의 출입문 번호 |

자주 보는 포트:

| 포트 | 용도 |
|---|---|
| 22 | SSH (원격 접속) |
| 80 | HTTP (암호화 안 된 웹) |
| 443 | HTTPS (암호화된 웹) |
| 3000, 8080 등 | 개발용·내부용 앱이 흔히 쓰는 번호 |

> 핵심: 포트 하나는 **한 번에 한 프로그램만** 쓸 수 있다. 사이트 여러 개가 모두 443을 쓰고 싶어 하면 충돌한다. 이 문제를 [07 리버스 프록시](07-reverse-proxy-https.md)에서 해결한다.

## 3. 리눅스와 Ubuntu

- 서버 OS는 대부분 리눅스다. 화면 없이 **명령어(터미널)**로 다룬다.
- **Ubuntu**는 리눅스 배포판 중 하나다. 우리 서버는 Ubuntu 24.04 LTS (LTS = 5년 장기 지원판).
- 자주 쓰는 명령:

| 명령 | 하는 일 |
|---|---|
| `ls`, `cd`, `pwd` | 목록, 이동, 현재 위치 |
| `cat 파일` | 파일 내용 보기 |
| `sudo 명령` | 관리자(root) 권한으로 실행 |
| `free -h` | 메모리 확인 |
| `df -h` | 디스크 확인 |
| `sudo ss -tlnp` | 어떤 프로그램이 어떤 포트를 열고 있는지 확인 |

## 4. SSH: 서버에 원격 접속하기

| 용어 | 한 줄 정의 | 비유 |
|---|---|---|
| **SSH** | 다른 컴퓨터의 터미널을 암호화된 연결로 쓰는 방법 | 원격 출입 |
| **키 쌍** | 공개키(서버에 둠) + 개인키(내 컴퓨터에 둠). 비밀번호 대신 쓴다 | 자물쇠(공개키)와 열쇠(개인키) |
| **`.pem` 파일** | Lightsail이 내려주는 개인키 파일. **절대 공유·커밋하지 않는다** | 열쇠 원본 |
| **`~/.ssh/config`** | 접속 정보를 별칭으로 저장해 두는 파일 | 단축 다이얼 |

`~/.ssh/config` 예시 (실제 값은 내 맥에만 있다):

```
Host aws-ubuntu-1
    HostName <SERVER_IP>
    User ubuntu
    IdentityFile ~/.ssh/<KEY>.pem
```

이렇게 해 두면 `ssh aws-ubuntu-1` 한 줄로 접속된다.
명령 하나만 실행하고 돌아오려면 `ssh aws-ubuntu-1 'free -h'`처럼 따옴표 안에 명령을 쓴다.
