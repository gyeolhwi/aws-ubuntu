# 05 도메인과 DNS·가비아 구매, 네임서버, A·와일드카드 레코드

> 학습 시리즈: [04 Compose](04-docker-compose.md) → **05** → [06 방화벽](06-firewall-ports.md)
> 상태: **완료** (2026-10-29)

## 1. 용어

| 용어 | 한 줄 정의 | 비유 |
|---|---|---|
| **도메인** | IP 대신 사람이 외우는 이름. `hwiii.com` | 건물 이름 |
| **서브도메인** | 도메인 앞에 붙는 이름. `pont-coffee.hwiii.com` | 건물 안 가게 간판 |
| **DNS** | 이름을 IP로 바꿔 주는 인터넷 전화번호부 | 114 안내 |
| **등록기관 (Registrar)** | 도메인을 사고 소유권을 관리하는 곳 | 건물 이름 등록처 |
| **네임서버** | 그 도메인의 전화번호부(레코드)를 실제로 들고 있는 서버 | 114 상담원 |
| **A 레코드** | "이 이름 → 이 IPv4 주소" 한 줄 | 전화번호부 한 줄 |
| **와일드카드 `*`** | 따로 적지 않은 모든 서브도메인에 적용되는 레코드 | "이 건물 모든 가게는 이 번지" |
| **`@`** | 서브도메인 없는 도메인 자체 (`hwiii.com`) | 건물 정문 |
| **TTL** | 다른 DNS가 이 답을 몇 초 동안 기억(캐시)할지 | 메모 유효기간 |

### 세 가지는 서로 다른 역할이다

| 역할 | 우리 경우 |
|---|---|
| 등록기관 (도메인을 산 곳) | 가비아 |
| 네임서버 (레코드를 들고 있는 곳) | 가비아 (`ns.gabia.co.kr` 외 2개) |
| 서버 (사이트가 실제로 도는 곳) | AWS Lightsail |

도메인과 서버를 다른 회사에서 사도 **네임서버를 옮길 필요는 없다.** 네임서버에 서버 IP만 적으면 된다.
"타사 네임서버"는 Cloudflare, Route 53 같은 다른 DNS 서비스를 쓰기로 정했을 때만 고른다.

> 핵심: DNS는 **건물(서버)까지만** 데려다준다. `*` 레코드 덕분에 어떤 서브도메인이든 같은 서버로 온다.
> 건물 안에서 어느 사이트로 보낼지는 [07 리버스 프록시](07-reverse-proxy-https.md)가 정한다.

## 2. 실제로 한 일

1. **[콘솔: 가비아]** `hwiii.com` 구매. 네임서버 설정은 **가비아 네임서버 이용**을 선택했다.
2. **[콘솔: 가비아]** My가비아 → 도메인 → `hwiii.com` → **DNS 관리** → 레코드 수정 → 아래 두 줄 추가 → **저장**

| 타입 | 호스트 | 값/위치 | TTL |
|---|---|---|---|
| A | `*` | `<SERVER_IP>` (Lightsail 고정 IP) | 600 |
| A | `@` | `<SERVER_IP>` | 600 |

와일드카드가 있으니 앞으로 사이트를 추가해도 DNS는 다시 건드리지 않는다.

## 3. 확인 방법

**[맥]** (기대 결과는 각 명령 아래 주석)

```sh
# 1) .com 최상위 서버가 이 도메인을 가비아 네임서버로 위임했는지
dig NS hwiii.com @a.gtld-servers.net +noall +authority
#   hwiii.com.  172800  IN  NS  ns.gabia.co.kr. ...

# 2) 가비아 네임서버에 직접 물어보기 (가장 먼저 반영됨)
dig +short @ns.gabia.co.kr A pont-coffee.hwiii.com

# 3) 일반 사용자가 쓰는 공용 DNS에서도 보이는지
dig +short @8.8.8.8 A pont-coffee.hwiii.com
```

2와 3 모두 `<SERVER_IP>`가 나오면 끝이다. `whois hwiii.com`으로 등록기관과 네임서버도 볼 수 있다.

## 4. 겪은 일

| 시점 | 관찰 | 의미 |
|---|---|---|
| 구매 직후 | 1번(위임)은 정상, 2번(가비아 직접 조회)은 **응답 없음** | 위임은 됐지만 레코드가 아직 하나도 없는 상태 |
| 레코드 입력 화면 | 스크린샷에선 맞게 입력했는데 조회 결과가 비어 있음 | **저장** 버튼을 누르기 전이었거나 반영 대기 중 |
| 저장 후 | 가비아·Google DNS 모두 `hwiii.com`, `pont-coffee.hwiii.com` → `<SERVER_IP>` | 완료 |

참고: 이 시점에 브라우저로 `http://pont-coffee.hwiii.com`에 접속하면 연결이 거부된다. 서버에 80 포트를 듣는 프로그램이 아직 없기 때문이다. 정상이다.

## 5. 되돌리기

**[콘솔: 가비아]** DNS 관리 → 해당 레코드 **삭제** → 저장. TTL(600초)이 지나면 다른 DNS에서도 사라진다.
